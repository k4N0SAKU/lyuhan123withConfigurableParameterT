# 第十一届全国密码技术竞赛复赛 A1-22 题《面向大模型隐私保护的密码方案软件设计实现》

## 典型场景业务需求

大模型在政务、企业业务场景广泛落地，模型推理、训练阶段会接触大量用户敏感数据。
直接明文输入用户隐私数据到大模型，会造成隐私泄露；而单纯依靠大模型本身无法实现
数据隐私隔离。需要结合隐私计算、安全多方计算等密码技术，在不泄露原始用户数据
前提下完成大模型推理计算，实现"数据可用不可见"。同时要兼顾推理时延、内存开销，
适配中小型企业部署的大模型服务。

## 密码功能与创新要求

1. 实现多方参与下大模型推理的密码保护流程，原始用户输入数据不出本地，仅密码
   处理后的密文参与模型推理，完成推理后返回推理结果，原始敏感数据不泄露；
2. 实现参与方身份认证、密文数据完整性校验、会话密钥生成、分发、更新、销毁
   全生命周期密钥管理；
3. 建立威胁模型，明确攻击者能力，需要抵御窃听攻击、中间人攻击、推理结果篡改、
   重放攻击、部分参与方合谋攻击；
4. 输出方案资源占用测试结果，包含代码规模、运行内存占用、单轮推理耗时、
   网络通信开销；
5. 在安全假设下，保证方案可抵抗至多 t 个参与方合谋，保证输入数据、中间计算
   状态的机密性；
6. 参赛作品需要说明解决的大模型业务实际痛点，与现有国内外同类型隐私保护大模型
   方案、开源框架进行对比，从安全强度、推理时延、资源开销、部署便捷性、商用密码
   合规角度分析优势与短板，提供可复现测试实验，禁止空泛论述。

创新要求：作品可在密码协议改进、密码原语轻量化适配大模型、降低隐私推理计算
开销等方面形成创新，创新点必须满足密码安全约束，方案可落地实现、安全可评估，
整体指标优于国内同类开源基线方案。

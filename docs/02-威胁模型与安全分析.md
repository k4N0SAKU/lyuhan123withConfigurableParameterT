## 1. 参与方、敌手与假设

### 1.1 参与方（n=3）

| 方 | 角色 | 长期秘密 | 会话秘密 |
|---|---|---|---|
| P0 客户端 | 数据持有方，唯一接触明文输入与最终结果 | SM2 静态私钥、证书 | **CKKS 完整私钥**（掩码解密，D5 修订）、通道密钥 |
| P1 密钥服务节点 | 认证中枢、密钥全生命周期、审计、MPC 参与方 | SM2 静态私钥（CA 根**离线**，不入节点） | 通道密钥（**无任何 CKKS 私钥材料**） |
| P2 推理服务节点 | 模型持有方，密文域计算 | SM2 静态私钥 | 通道密钥（**无任何 CKKS 私钥材料**） |

### 1.2 敌手分类与能力表

| 敌手 | 能力 | 不具备 | 防御目标 |
|---|---|---|---|
| A1 被动窃听者 | tap 全部链路字节 + 无限离线计算（记录现在、离线分析） | 破译 SM2/SM3/SM4-GCM/CKKS（密码假设 §1.3） | 输入与中间明文不可恢复（F7-1） |
| A2 主动网络敌手（Dolev-Yao） | 窃听+篡改/重放/注入/延迟重组任意消息 | 控制节点内存；伪造 CA 签名 | 篡改可检测（F7-3）、重放可拒绝（F7-4） |
| A3 伪造接入者（外部 MitM） | 自签/异根证书冒充任一节点发起握手；双向中继 | CA 根私钥；任一诚实节点的静态私钥 | 认证拒绝+审计告警（F7-2） |
| A4 半诚实参与方（static, t≤1） | 严格按协议执行但记录**全部**收发消息与内存视图 | 偏离协议（恶意行为可检测不可防，§1.4） | 视图可模拟（§5）；输入隐私（F8 t=1） |
| A5 合谋（t=2） | 两方交换全部视图 | 第三方视图 | **超出防御边界**——如实声明（§3.3/F8 边界演示） |

### 1.3 密码假设

| 假设 | 口径 | 依据/锚点 |
|---|---|---|
| SM2 签名 EUF-CMA | 国标曲线+上下文分隔（跨协议重放不可行） | gmssl；RFC 8998/GB/T 32918 结构；test_auth 拒绝矩阵 |
| SM3 近随机预言机 | 256-bit 抗原像/抗碰撞 | GM/T 0004；国标向量锚定 |
| SM4-GCM AE（IND-CPA+INT-CTXT） | 96-bit nonce 绝不复用（nonce=方向标签‖seq，序列号严格单调） | RFC 8998 附录 A.1 逐字节锚定 + 单零块断言 |
| CKKS IND-CPA（RLWE 128-bit classical） | 2^15/200bit 主线（estimator 复核值见 results/security_estimator.json） | SEAL TC128 校验 + lattice-estimator |
| 掩码一次性 | 入口 r∈[0,2⁴⁹) 2¹¹ 网格均匀、出口 s∈[2²⁵,2³⁶) 均匀（ConversionPolicy） | os.urandom 拒绝采样；test_conversion 分布断言 |
| Beaver 三元组可信离线 | D7——生成器可信且离线（三方不同权管辖，§6 假设表 A-1） | offline_triple_gen.py；SM3 校验和 |
| 时钟偏移 ≤±30s | 时间戳容差窗 | 注入时钟测试（陷阱 1 纪律） |

### 1.4 安全边界声明（S8，如实申报）

- **半诚实参与方 + 恶意网络敌手**；不声称恶意参与方安全——注入构造性密文/
  扣留份额=拒绝服务，可检测（审计）不可防；
- 覆写销毁为**进程内存级**（bytearray 两遍覆写）；bytes 拷贝不可回收（Python
  语义），不抵御 cold-boot/侧信道——商用需 TEE；
- 模型对 P0 公开（嵌入查表在 P0 本地，docs/01 §2.2 信息论论证）——输入隐私
  保护目标=用户输入与中间激活，不含模型机密性；
- 回环同机模拟口径（S8）：链路为进程内/多进程队列，非真实 socket——网络层
  攻击面（TCP 层 DoS/端口扫描）不在测试范围；密码层与传输层解耦，
  真实 socket 化不改变协议语义。

## 3. 合谋抵抗分析

### 3.1 视图（F8 取证口径）

- **P0**：明文输入/输出、CKKS 私钥、掩码解密值 y₁=x+r（白名单①）、最终输出
  （白名单②）；
- **P1**：控制面消息、y₁（OTP）、出口 OTP 值 z=a₁+s、Enc(s)、MPC 交互、审计；
- **P2**：全部密文（Enc(r)/Enc(s)）、−r、w=v+s、模型权重、MPC open、密文域
  合成能力；
- 线缆字节：三链路全部 GCM 帧（密文）+握手期签名帧。

### 3.2 t=1 抵抗（F8 自动化断言）

- **P2 单独**：无钥不可解（RLWE）+ −r 均匀掩码与明文统计独立
  （test_p2_alone：|r|<0.2 断言 + public_only 结构断言）⇒ 计算安全；
- **P1 单独**：y₁=QKV输出+r，r 为 P2 fresh 均匀掩码 ⇒ 信息论一次一密；
  已知模型侧区分攻击（候选嵌入→推算 QKV 输出→残差落窗率）无检验力
  （test_p1_alone：相关 |r|=0.015、落窗率差 <0.01）；
- **P0 单独**：协议流向 P0 的解密仅掩码值与最终输出（DecryptionWhitelist
  结构防线，拒绝事件入审计）——半诚实下私钥不构成超出角色的泄露。
  ⇒ **无单点泄露**（F8 t=1 全部「防御成功」）。

### 3.3 t=2 失效面（D3 要求，如实声明+自动化演示）

| 合谋 | 获得 | 破坏 D3？ | F8 演示 |
|---|---|---|---|
| P1+P2 | y₁+y₂ = x+e：**全部中间态明文** | **是**（掩码分享构造的固有边界） | 模式 B test_p1p2_collusion：QKV 输出重构（err<0.05）→ W 求逆回嵌入 → 词表最近邻 **token 恢复成功**——「边界演示」判定 |
| P0+P2 | 全钥+全部密文 ⇒ 全解 | 是 | 未演示（P0 本为解密方，语义平凡） |
| P0+P1 | P0 本就是解密方；P1 无钥可加成 | 是 | 未演示（同上） |

**结论**：安全性精确到 t=1。缓解（扩展方向，非本期承诺）：模式 A 全密文
（F8-模式A 已演示 t=2 下输入不可恢复——CKKS IND-CPA）、2-of-3 门限。

### 3.4 前向安全

K_{i+1}=SM3(K_i‖H_i)：恢复 K_{i<j} 需逆 SM3（2^256）；ratchet 后旧纪元密钥
窗口外覆写（keylifecycle）；审计链 append-only 同理。测试锚点：
test_keylifecycle::test_ratchet_forward_secrecy_semantics、
test_replay::test_replay_after_ratchet_rejected。

## 4. 逐算子安全分析

| 算子 | 安全性 | 依据/申报 |
|---|---|---|
| 密文线性层（BSGS 对角） | CKKS 同态（IND-CPA 组合闭包） | 密文×明文不引入交互；对角线/gap-block 为公开编码 |
| QKV 密文偏置加法 | 同上 | add_plain 常量为公开派生值 |
| 转换入口（掩码） | OTP（r 全窗均匀，floods 值域） | P2 fresh os.urandom；test_conversion 分布断言；F8-模式B 钩子 |
| 转换出口（再随机化） | OTP（s 偏置窗）+ 密文域合成 | P1 持 s 不见 a₂；P2 见 w=v+s 不见 v/s；fresh 顶层（深度重置） |
| MPC reveal-compute-reshare（S8 模拟） | 半诚实 Beaver 语义 | open 消息为 x−a 均匀化；**申报**：数值精度为 numpy 全精度（真实 MPC 定点求值=P3 xfail 项），门数/字节如实记账 |
| LN/GELU/softmax（明文域重计算） | S8 模拟口径 | 重计算在 P1 侧（已知中间态假设下不增加泄露）；门数记账 |
| 定点截断（probabilistic/MPC 域） | **概率性偏差声明** | 截断为“重构-截断-重分享”语义（P3）；偏差计入 Q16 量化误差预算（§1.3） |
| 解密白名单 | 结构性防线 | P0 私钥唯一访问门；拒绝事件入审计；tests/attack+e2e 锚点 |

**Beaver open 与三元组消耗对账**：MpcEnv 逐门耗三元组（gate_id 严格递增），
open 消息 (d,e)=(x−a,y−b) 消耗后 a,b 不复用——账目在 MpcEnv.gates_used/
comm_bytes 中可审计（P3 基准口径）。

**转换掩码 fresh 性运行时断言**：同一 request_id 的掩码仅采样一次
（`pending_masks.pop`），重用即 KeyError——协议层结构性排除掩码重用。

## 5. 安全性论证（半诚实模拟器思路，简化证明）

**定理（简化）**：在 §1.3 假设下，t≤1 半诚实静态敌手视角下协议执行与
理想世界不可区分（计算意义，模式 B；模式 A 归约到 CKKS IND-CPA）。

**证明思路（每句“可模拟”给出构造）**：

1. **P1 的视图可模拟**。P1 视图 = ①握手/控制面消息 ②y₁ ③z 与 Enc(s) ④MPC
   open。构造模拟器 S₁：①以真实证书/签名逐帧重放（半诚实下消息流为公共
   transcript）；②y₁ ← Uniform[0,2⁴⁹)：与真实分布不可区分，因为 r 由 P2
   从 [0,2⁴⁹) 2¹¹ 网格均匀采样（ConversionPolicy.mode-b）、定点值域
   |x·2¹⁶|<2²⁴ ≪ 窗宽——y₁=x+r 支撑集 [0,2⁴⁹+2²⁴)，统计距离
   ≤2·2²⁴/2⁴⁹=2⁻²⁴（OTP 判据，docs/01 §7.4）；③z ← Uniform[0,2⁶⁴)
   **精确**（z=(a₁+s) mod 2⁶⁴，a₁ 来自均匀分享份额——群上均匀分布的平移
   不变性，与 s 的窗位置无关）；Enc(s) 由真实公钥
   加密 S₁ 自选的 s'（IND-CPA ⇒ 与 Enc(s) 不可区分，归约：若可区分则构造
   CKKS 区分器）；④MPC open 消息 x−a 中 a 为离线均匀三元组份额 ⇒
   x−a 均匀（ Beaver 语义）。
2. **P2 的视图可模拟**。S₂：①控制面同 1①；②密文一律由真实公钥对任意
   消息加密（IND-CPA ⇒ 与真实密文不可区分）；③−r ← Uniform[0,2⁶⁴)
   （r 均匀的负元）；④w=v+s：S₂ 知 −r 但 v 未知——w ← Uniform[2²⁵,
   2³⁶+2²⁴)（s∈[2²⁵,2³⁶) 偏置窗，|v|<2²⁴ ⇒ 真实 w 支撑集
   [2²⁵−2²⁴, 2³⁶+2²⁴)；与模拟分布的总变差距离 ≤2·2²⁴/(2³⁶−2²⁵)≈2⁻¹⁰）。⑤Enc(s)：S₂ 无法得知
   P1 的 s——但它可自选 s'' 并加密（Enc(s) 在 P2 视图中只是密文，
   IND-CPA 下与任意明文的加密不可区分）。
3. **P0 的视图可模拟**。S₀：①控制面同上；②y₁ ← Uniform[0,2⁴⁹)
   （y₁=x+r，r 均匀 ⇒ y₁ 统计均匀于 [0,2⁴⁹+2²⁴)，统计距离 ≤2⁻²⁴，同 1②）；③最终输出=功能输出
   （理想功能 F：明文→分类结果），半诚实定义下 P0 本就接收它。
4. **组合**：模拟器仅使用公共参数（公钥/模型形状/消息类型计数）与理想
   功能输出——逐帧对照协议步骤（docs/01 §4.1/§7.4），无任何真实中间值
   进入模拟。故任意 t≤1 视图与真实执行计算不可区分。∎

**证明边界（如实申报）**：①模拟仅覆盖 S8 申报口径——MPC 非线性为
reveal-compute-reshare 模拟（open 消息语义真实，数值全精度）；②「值域
守卫」是 OTP 判据的前提：越界即协议中止（ConversionError），不产生弱
密文；③恶意参与方（伪造份额/提前中止）不在证明范围（§1.4）。

## 7. 已知不可防御项与元数据边界（如实声明）

- **可检测不可防**：注入构造性密文、扣留份额、提前中止（DoS）——审计告警
  + 状态机拒绝，但可用性受损；
- **元数据可见**：msg_type/帧长/时序/会话 id（header 明文，AAD 覆盖完整性
  但不加密）——流量分析可获知交互模式（隐匿通信为非目标）；
- **t=2 合谋**：模式 B 全部中间态（§3.3，F8 边界演示）；模式 A 下仍安全
  （F8-模式A 防御成功）；
- **侧信道/cold-boot**：超出软件层威胁模型（A-8）；
- **审计链头固化**：链内防篡改已实现，链头外部锚定（可信时间戳/区块链）
  为扩展方向。

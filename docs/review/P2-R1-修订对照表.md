## 核验要点（供评审人）

1. RFC 8998 向量在修复后实现上逐字节匹配（`test_rfc8998_sm4_gcm_vector`）；
2. 单零块断言 `ct == E(K, J0+1)` 通过（`test_counter_convention_single_zero_block`）；
3. minimax 系数独立复算与等波纹性自检通过（`test_minimax.py`）；
4. docs/01 表 4/§7.5 与 nonlinear_approx.py 规格三方一致（锚定测试）；
5. C 项复现实验与 5 轮 packing 基准结果（工作记录 §9 补充记录）。

## API 探针（陷阱 1 执行记录）
TenSEAL 高层无旋转 API → sealapi 原生 SEAL 绑定；**n≥2^16 一律拒绝（本栈上限
2^15）**；Modulus(40) 是值 40 非 40-bit 素数（用 CoeffModulus.Create）；rotate(+k)
=左移；invariant_noise_budget 不支持 CKKS；scale=1.0 编码静默全零；Ciphertext
无拷贝构造（文件克隆）；gmssl _kg 可用（SM2DH 原语闭环）+ ecc_table 怪癖
（Z_A 用国标常数）；SM4 padding_mode=None 单块原语（pycryptodomex 无 SM4）。

## 微基准（P50）

CKKS 256 元素：加密 26.9/解密 6.1/明文乘 10.5/密文乘 21.1/旋转 18.2ms；
线性层 768×768×L2 = **4.15s**（5 轮豁免口径）。

## 2. API 探针（陷阱 1"先跑示例再封装"的执行记录）

| 探针 | 结论 |
|---|---|
| TenSEAL 高层 API | `ts.context` 不接受 scale 参数（用 `ctx.global_scale`）；**CKKSVector 无旋转 API**（Python/pybind 层均无） |
| sealapi | TenSEAL 0.3.14 内置**完整原生 SEAL 绑定**（Evaluator.rotate_vector/rescale_to_next/CKKSEncoder/KeyGenerator…）→ ckks_ops 据此实现 |
| 参数上限 | **n≥2^16 一律 `invalid_parameters_insecure`**（与链长无关，实测 n=2^16 连 [60,40,60] 极小链亦被拒）；n=2^15 实测最大链 880bit 通过 |
| `Modulus(40)` 陷阱 | 构造的是"值=40"的模数，40-bit 素数必须用 `CoeffModulus.Create` |
| 旋转语义 | rotate_vector(ct, +1) = **左移**（res[s]=v[s+1]） |
| invariant_noise_budget | **不支持 CKKS**（unsupported scheme）→ 改 decrypt_error_rmse |
| scale=1.0 明文编码 | **静默产生全零明文**（ifft 小系数被 round 抹零）→ 掩码必须用正常 scale |
| Ciphertext 拷贝 | pybind 无拷贝构造 → mod_switch 用文件往返克隆 |
| gmssl | `_kg/_double_point/_add_point` 可用 → SM2 密钥生成 + ECDH 原语自实现（**J 项闭环**）；ecc_table 无 gx/gy 键且 'g' 带填充怪癖 → Z_A 用国标常数 |
| gmssl SM4 | `padding_mode=None` 可得无 padding 单块原语 → GCM 基于其自实现；pycryptodomex 无 SM4（无参考实现，用国标向量+代数性质+自洽测试） |

## 3. 参数实测 vs P1 估算——偏差分析（出口条件 4）

| # | 项 | P1 估算 | P2 实测 | 影响 |
|---|---|---|---|---|
| 1 | poly 上限 | 2^16/2^17 可用 | **2^15 为本栈硬上限**（SEAL 校验表） | 表 7 修订：mode-b 16384 槽（10 块/密文）、密文 1.64MB；mode-b-large 取消（L=16 需 2 密文，转换 192 次）；**mode-a 本栈不可演示**（提请团队决策：理论推演 or OpenFHE） |
| 2 | ε_ckks | 相对 ≤1e-6（|m|~1 隐含） | **绝对量**：2 层链 3.8e-9、14 层深链 7.1e-9 @2^40 | 回归指标改绝对 RMSE（阈值 1e-6，余量 >100×）；相对误差取决于消息幅值 |
| 3 | 噪声观测 | invariant_noise_budget | **不支持 CKKS** | decrypt_error_rmse（已知明文对照） |
| 4 | ρ（旋转/乘时间） | 假设 8 | **≈1.7**（rotate 18.2ms / mul_plain 10.5ms @256 元素） | §6.2 选型排序**反转**：row-sum 或快 ~1.3× → P3 双实现 A/B（C3 素材）；布局/实现简洁性理由仍成立 |
| 5 | 线性层时延 | 未给秒级 | **768×768×L2 全层 4.15s**（768 明文乘+54 旋转+rescale） | P3 外推：BERT 单层 ~13 chunk ≈ 54s，12 层 ≈ 11 min/请求（L=2，CPU）——时延优化的量化基线 |
| 6 | 旋转噪声 | 未测 | 旋转 ~1e-6 > 乘法噪声（2e-8@深度2） | 旋转次数进入噪声与时延双重预算 |
| 7 | 掩码编码 | 未 specified | scale=1.0 静默全零 | 掩码用正常 scale；模式 B 布局重置移至转换出口（P1 编码，免费） |
| 8 | BSGS giant 组 | 未 specified 预旋转 | 明文需预旋转 +j·baby（块周期性保证正确） | 实现细节入文档；块后半槽不再恒 0（上層只读前 d 槽） |

## 5. 测试结果

- **pytest 131/131 全绿**（单元 127 + 端到端 4；P1 末 71 → 新增 60）：
  - ckks：roundtrip/乘法/旋转/深度记账/mod-switch/序列化/公钥上下文拒绝/精度回归（2 层 ≤1e-6、深链实测 7.1e-9）/mode-a 拒绝实例化；
  - packing：对角线定义/单层 vs numpy/两层复合（含 replicate）/真实 768 shape（slow）；
  - sharing：代数 + 比特频率（4σ）+ 卡方 + "单份额无信息"双分布对照；
  - beaver：在线乘法正确性（50 组随机）/消耗对账/库存篡改检测/CLI 生成进程；
  - gm：SM3 国标双向量、KDF、SM2 签验/跨上下文拒绝/加解密/ECDH 一致性、SM4-GCM 往返/密文-AAD-tag-nonce 四类篡改检测/GM-T 0002 ECB 向量/GF(2^128) 代数性质；
  - threshold：正负值恢复/缺份额/同方重复/伪造承诺/销毁拒绝。

## 6. 遇到的问题与修复

1. BSGS giant 组旋转后明文索引错位 → 明文预旋转 +j·baby（numpy roll）；
2. scale=1.0 掩码编码全零 → 掩码正常 scale + 同 level 累加一次 rescale；
3. rescale 后 scale ulp 漂移导致 SEAL 加法 "scale mismatch" → `_align_scale` 显式对齐；
4. 密文乘 level 不对齐 "parameter mismatch" → 调用方 mod_switch 对齐（文档口径）；
5. gmssl public_key=None 崩溃 / ecc_table 怪癖 → 类级探针 + 国标常数；
6. SM4-GCM nonce 未返回导致解密错位 → nonce 改为显式必填参数（顺带强化 F6）；
7. 门限模拟 p_i 代数错误（2b−a·s）→ 非对称份额修正（p₀=b−a·s₀, p₁=−a·s₁）；
8. 均匀性 3σ 检验偶发失败 → 4σ 界（64 比特同检的统计功效分析）。

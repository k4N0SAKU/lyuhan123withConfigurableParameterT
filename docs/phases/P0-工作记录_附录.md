## 完成内容
1. 环境：Python 3.10.4 venv；依赖锁定 requirements.txt（numpy 1.26.4 因 TenSEAL
   ABI、torch 2.6.0+cpu、transformers 4.49.0、tenseal 0.3.14、gmssl 3.2.2）；
   环境自检 `python -m src.common.envinfo`（版本+CKKS/SM3 冒烟）。
2. 性能采集框架 src/common/perf.py（a122-perf/1：分段计时/P50-P95/RSS/网络字节）+
   netmeter.py（socket 计数封装）；标准分段名常量。
3. 明文基线：GPT-2 贪心生成（单轮 16 token P50=792.4/P95=856.5ms，20 轮 CPU
   ——权威口径为 2026-09-25 04:17 UTC 重跑轮）；BERT 情感分类（P50=38.4/P95=49.0ms；
   FP32 acc 99.0%）。
4. 自建中文情感数据集 600 条（train 400/eval 200，9 类场景，合成无个人信息，
   校验测试强制隐私红线）。
5. 模拟定点化 quantize.py（激活 Q 可配置起步 13、权重档位 int8/fp16/q22、
   溢出断言 raise/clamp）；eval_quantize.py 阈值断言。
6. 量化档位阶梯：INT8 0.891 → FP16 0.944 → Q22+Q13 0.944 → **Q22+Q16 = 1.000**
   （达标 ≥95%）；分类下降 0.00pp（≤1.5pp 达标）。
7. run_ci.py 本地全量质量门；demo_plaintext.py 一条命令 Demo。

## 关键发现
- 贪心解码混沌敏感性：logit 近并列 ~1e-5 即级联发散（INT8/FP16 权重不达标，
  需 Q22）；fp-vs-fp 自洽 20/20 排除线程非确定性。
- 绑定权重（wte≡lm_head）量化须去重只做一次。

## 1. 背景与动机

题面第 5 条：「在安全假设下，保证方案可抵抗至多 t 个参与方合谋，保证输入
数据、中间计算状态的机密性」。t 为自报参数。现交付口径 n=3、计算方间
t=1（精确到门限 + t=2 失效面自动化演示）合法达标；本提案把 t 升级为
**部署可配置的门限族**——语义对标 Shamir (k,n) 的部署选参，且落在隐私
上限 t = m−1。

## 2. 威胁模型重申报（D 级变更，需评审）

|---|---|---|
| 参与方 | n=3（P0/P1/P2） | **1+m 方**（P0 数据属主 + m 个计算方 P1..Pm；首发 m=3） |

## 3. 协议规格（D5′，conversion_m.py 为代码权威载体）

**入口（ct → m 份额）**：掩码链 P2→P3→…→Pm→P1，各计算方独立采样掩码片
rᵢ 并密文域叠加 Enc(rᵢ)（按目标精确 scale 编码+mod_switch 对齐）→ P0
白名单①解密 y = x+Σrᵢ → y 分发锚点 P1（holder=1）。份额：x₁ = y−r₁
（锚点），xᵢ = −rᵢ（i≥2）⇒ Σxᵢ = x (mod 2⁶⁴)。

**出口（m 份额 → ct）**：各 Pᵢ 独立采样 sᵢ，发 (zᵢ = aᵢ+sᵢ, Enc(sᵢ)) 给
合成方 P2；P2：w = Σzᵢ = v+Σsᵢ（m 缩放界守卫）→ ct = Enc(w)−ΣEnc(sᵢ)
= Enc(v)，fresh 顶层密文。

**MPC 域**：m-of-m 加性分享（secret_sharing_m）+ m 方 Beaver
（beaver_m：open 广播 dᵢ/eᵢ，d·e 记 P1 一方）。

**安全论证（信息论 OTP）**：任意 t ≤ m−1 方合谋至少缺一片均匀掩码——
入口条件窗 = 单片窗 [0, entry_hi)（网格 2¹¹），出口条件窗 = 单片偏置窗
[lo, hi)。**泄漏界与单片版相同，不随 m 劣化**。合谋矩阵测试实证：6 视角
×入口/出口，精确恢复成功率 0，含锚点/合成方组合的候选-真值差恰好落缺失
片窗内。

**量级墙（m 上限，check_m 强制）**：y/w ≤ m·窗 + 值域 ≤ 2⁵³（float64
精确整数域）⇒ mode-b **m ≤ 15**、p4-toy m ≤ 8191。

- m-of-m 零容错：任一计算方掉线协议停滞（无 Shamir k<n 冗余；换冗余需
  环上拉格朗日=域论代价，登记为后续路线）；

- 管线级 prob 等价窗 ±1 ulp（CKKS 解码边界，与 [K] 一致率口径一致）。

## 4. 创新点验证（docs/05，摘要）

### C2 量化参数自适应
- **正结果**：conv_fp16 + emb_q22 = 一致率 **1.000** @ 体积 **312.7 MiB**
  （默认 474.7 MiB，**−34.1%**）；
- **诚实负结果**：逐张量 2% 误差阈值选择器失效（int8 相对误差普遍 <2% 但
  端到端 0.8906）；层级升级 12 步 trace 全程卡 0.8906（int8 基座上级联
  已定型，fp16 二次量化无法修复）——**参数选择的正确形态=端到端闸门 +
  从参考域单次量化**；
- 定向变体四点：emb_fp16=0.9437（差 0.63pp）、emb_int8=0.3063（灾难）、
  conv_int8=0.8906、conv_fp16=1.000——合规域离散单点+conv_fp16 点；
- **锚点**：FP32 参考管线（定义 1.000）+ P0 默认档 1.000 可复现。
- 安全约束：量化仅在 P0 本地明文域，密码参数零变动（docs/05 §1.5）。

### C3 双实现 A/B
- row-sum 对照实现（`src/model/ops/rowsum.py`，循环旋转公式 + 环上复制，
  正确性 decrypt 对照 9.8e-8/2.4e-6）；
- **实测 5.39×/5.14×（d=256/512，JSON 实测）慢于对角线+BSGS**——P2"row-sum 或快
  1.3×"推测否定；解析 ρ 单位模型低估环上全宽明文编码成本；
- 决策：维持对角线+BSGS；row-sum 留作对照（安全语义等价，选型纯性能维度）。

## 1. 演示系统设计与实现

- **流程**：PROVISION → AUTHENTICATING（三链路真实握手，玩具 CKKS 通道）
  → SESSION_READY → 逐轮 INFERRING（真实管线 n_layer=2/L=8，~88s/轮）
  → DECRYPTING（D5 白名单②+业务映射标签）→ DESTROYING（两遍覆写+审计链
  核验）→ DONE；异常/超时 → FAILED（error 面板）。
- **口径纪律（陷阱 2）**：指标统计全部经 `src.common.perf` 的
  `_stats_block/NetworkMeter/MemoryTracker`（与 p6 JSON 同一函数）；基线
  对照直读 `p6_full_bench.json`（页面标注 source）。
- **明文灯（F2 运行时钩子）**：每轮递归扫描 P1/P2 全字段视图（生命周期
  节点 + 管线角色），输入文本/敏感字段 hex 模式 0 命中才亮绿——与
  tests/attack F8 钩子同技法；线缆证据引用 F7-1。
- **模式 A 切换**：点按即进入如实面板（本栈 SEAL 2^15 上限不可实例化，
  不做假运行）——一键切换 UX 满足、口径不冒充。
- **场景**：政务诉求情绪研判 / 企业工单敏感分类；姓名/证件号为虚构
  字段并页面常驻"模拟数据"标注（陷阱 1）；业务语义=情感二分类映射示例
  （截断管线口径在页面与文档双处标注）。

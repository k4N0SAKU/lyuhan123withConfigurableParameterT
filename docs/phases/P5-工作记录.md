## 1. 攻击套件架构

- **framework.py**：
  - `RecordingEndpoint`——链路记录端点（窃听者=两端发出帧全集）；
  - `collect_view`——角色**全字段内存取证**（含 `_secret_ctx`/`_pending_r`
    私有成员；hex 编码防类型歧义）——F8 钩子证明与 F2 内存扫描钩子的数据源；
  - `VerdictRecorder`——判定记录器（会话结束自动落盘，assert 判定域）；
  - 统计工具：`chi2_uniformity`（密文均匀性）、`pearson`（已知明文相关）、
    `scan_pattern`（明文模式扫描）。
- **conftest.py**：会话级 CA 夹具 + `pytest_sessionfinish` 收尾落盘。
- 每类攻击独立可运行（独立文件、独立 verdict 记录、失败即 "防御失败"）。

## 2. 五类攻击要点（详见 docs/03）

1. **窃听 F7-1**（5 判定✅）：明文模式扫描（UTF-8/GBK/token id/Q16 定点）0
   命中；GCM 帧载荷不可解析（payload_type 加密）；密文卡方均匀；已知明文
   相关 |r|<0.2。
2. **中间人 F7-2**（6 判定✅）：三种伪造接入+异 CA 根+双向中继全部认证拒绝
   **且留审计告警**——P5 补齐 `_accept_cert` 拒绝路径的 SECURITY_ALERT
   （P4 时仅会话期有告警钩子，握手期拒绝不留痕，攻击测试暴露后修复）；
   诚实握手对照防误伤。
3. **结果篡改 F7-3**（5 判定✅）：密文/签名/元数据三类篡改 + 无钥伪造整帧
   → CTX_RESULT 验签拒绝；诚实对照通过。
4. **重放 F7-4**（5 判定✅）：同会话/多份/跨会话/ratchet 后/改 seq 五路径
   全拒绝（seq 先于解密；header 在 AAD 内，改 seq=tag 失败）。
5. **合谋 F8**（模式 A 4✅；模式 B 3✅+2 边界演示）：
   - 模式 A：t=2 合谋视图无钥（结构断言）+ 无明文量级值（内存扫描）+
     已知明文区分攻击无检验力（重加密字节重合率 ≈1/256、密文尺寸在随机
     带宽内）——**防御成功**；
   - 模式 B t=1：钩子证明（P1/P2 视图 0 命中输入串/token id）+ P1 侧已知
     模型残差落窗率检验（区分力 <0.01）+ P2 侧结构断言——**防御成功**；
   - 模式 B t=2：**边界演示**——y₁+(−r) 重构 QKV 输出（err≈4e-3，玩具
     CKKS 噪声经 768 维求逆放大，嵌入量级内不影响恢复）→ W_q 求逆回嵌入
     → 词表最近邻 **token0 恢复成功**——与 docs/02 §3.3 失效面声明一致，
     测试将其转为可复现证据（缓解=模式 A/2-of-3 门限）。

**陷阱应对**（"只做无法直接解密不够"）：三类主动区分攻击均已量化——
①P1 已知模型残差落窗率；②模式 A 重加密相关+长度信号；③t=2 嵌入最近邻
重构。

## 3. 安全论证（docs/02 §5）

半诚实模拟器简化证明：P1/P2/P0 三方视图逐一给出模拟器构造——
①控制面=公共 transcript 重放；②y₁/z/w ← 均匀（OTP 判据：掩码窗/值域
≥2²⁵，统计距离 ≤2⁻²⁴，实测量级）；③Enc(s) 自选明文加密（IND-CPA 归约）；
④MPC open=x−a 均匀（Beaver 三元组语义）。证明边界如实申报：S8 模拟口径
（非线性 RCR 模拟）、值域守卫为 OTP 前提（越界即中止）、恶意行为不设防。

## 4. P5 实测发现与修复

| 发现 | 处置 |
|---|---|
| 握手期证书拒绝不留审计（P4 缺口） | `_accept_cert` 增加 SECURITY_ALERT（CERT_INVALID/CERT_EXPIRED+冒用身份记录），攻击测试断言留痕 |
| `wire_bytes` 把帧列表当帧拼接 | framework 修复（展平） |
| 密文尺寸浮动疑似长度泄露 | 实测证明为加密随机性（同明文重加密同样浮动）——断言改为"同明文基线带宽"口径，证据入 verdicts |
| toy 槽 1024 < 2×768 | F8 模式 B 承载 token0 的 768 维 QKV 输出（重构攻击语义不变，多 token 仅扩大同一失效面） |
| CKKS 重构误差 4e-3 | 玩具噪声经 768 维求逆放大——按嵌入量级定容差（<0.05），词表最近邻不受影响 |

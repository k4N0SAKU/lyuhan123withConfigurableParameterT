## 5. P3-R1 修订轮详细内容（2026-09-26）

### 5.1 管线四个结构性数值 bug（本轮最重要产出）

| # | Bug | 修复 |
|---|---|---|
| 1 | 转换掩码未重构：_convert_to_shares 返回 y₁=x+r（P1 视角）而管线直接当明文消费，r~2⁶³ 从未移除 → 全转换点 ~1e13 垃圾（**总根因**） | 模拟器持双方视图：返回 (y₁−r)=x·2¹⁶（重构语义=y₁+(−r)，协议语义不变） |
| 2 | FFN 权重切片转置：`.T[:,:d]` 实际取 W[j,i] | `[:d,:]` / `[:,:d]`（W@x 语义=transformers y=x@W.T） |
| 3 | 布局不变量破坏：残差加输出（前半槽有效+后半槽 BSGS 垃圾）直接进入下一线性段，环绕项读垃圾 | 每个线性段输入改为**转换出口 fresh 双拷贝密文**（docs/01 §7.4 出口编码免费重置） |
| 4 | post-LN 两个 LayerNorm 缺失 | LN1/LN2 作为转换点补齐（reveal-compute-reshare，门数 8/元素记账） |

## 8. 关键教训索引（详见各阶段工作记录）

- 密码组合层必须有**外部标准向量**锚定（P2-R1 A：计数器偏移自洽测试全绿仍非标准）；
- RCR 模拟层的**掩码必须重构**（P3-R1：返回 y₁ 未减 r → 全管线垃圾）；
- 每线性段输入必须是转换出口 fresh 双拷贝（布局不变量）；
- CKKS 槽数=N/2；scale=1.0 编码静默全零；Modulus(bit) 是值不是位宽；invariant_noise_budget 不支持 CKKS；CKKS 噪声是绝对量；
- 性能 JSON 禁绝对路径（write_report 已内置归一化）；测试双口径申报格式固定。

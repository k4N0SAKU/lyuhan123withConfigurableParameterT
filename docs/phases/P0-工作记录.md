## 2. 任务完成清单

### 第一轮（初始 P0）
1. 仓库骨架：按总纲第八节建目录树 + 各包 `__init__.py` docstring；git init（main 分支）。
2. 性能采集框架 `src/common/perf.py`：SegmentTimer（分段计时）、NetworkMeter（字节计数）、MemoryTracker（psutil RSS 峰值采样）、PerfSession（多轮驱动 + P50/P95 统计）、`a122-perf/1` 报告模式；标准分段名常量（AUTH/KEYNEG/ENCRYPT/TRANSPORT/COMPUTE_LINEAR/COMPUTE_NONLINEAR/THRESH_DECRYPT 等）——为后续阶段埋点口径统一。
3. 环境信息采集 `src/common/envinfo.py`（CPU/内存/GPU/包版本/网络拓扑口径）。
4. 明文基线 + `benchmarks/perf_runner.py` CLI（dryrun/gpt2/bert 三工作负载）+ 模型下载脚本 + 演示数据。
5. README、.gitignore、pyproject.toml（pytest 配置）、空转自检测试。

### 第二轮（团队扩展任务）
1. **环境自检脚本**：`python -m src.common.envinfo`——版本打印 + CKKS 冒烟（x²+x 正确性）+ SM3 标准向量（sm3("abc")=66c7f0f4…）+ torch 线程信息。
2. **socket 字节计数封装** `src/common/netmeter.py`：CountingSocket 包装 send/sendall/recv 计数（socketpair 实测）。
3. **src/model/loader.py**：GPT2GreedyPipeline（贪心解码，逐 token 埋点）+ BertSentimentPipeline（分类）——模型加载与推理逻辑的唯一实现；可选注入 FixedPointQuantizer。
4. **自建中文情感数据集 600 条**：`data/sentiment/train.tsv`（400，正负各 200）+ `eval.tsv`（200，正负各 100），9 类场景（政务办事/购物/餐饮/出行/医疗/教育/物业/售后/公共服务）；全部合成短句、无真实个人信息（≥11 位数字串在测试中被禁止）；`data/README.md` 数据说明。
5. **模拟定点化** `src/model/quantize.py`：FixedPointQuantizer（frac_bits 可配置，起步 13；on_overflow=raise/clamp，溢出断言）+ per-channel INT8 + fp16 Q/DQ + 绑定权重去重 + 激活 Q/DQ forward hook 注册。
6. **BERT 微调** `benchmarks/finetune_bert.py`：seed=42、lr 2e-5、batch 16、4 epochs，按 eval acc 保存最优 → **FP32 eval acc 99.0%**（epoch 2），`train_meta.json` 记录全部超参。
7. **定点化精度评估** `benchmarks/eval_quantize.py`：GPT-2 token 一致率（20 prompts × 16 tokens）+ BERT accuracy 对比 + 阈值断言（≥95% / ≤1.5pp）+ JSON 报告（`a122-quantize-eval/1`）。
8. **一条命令 Demo** `benchmarks/demo_plaintext.py`：GPT-2 生成 + BERT 三句分类。
9. **本地全量跑** `benchmarks/run_ci.py`：环境自检 → pytest 全量（覆盖 slow）→ 双基线重采 → 定点化断言 → JSON/打印一致性复核，任一步失败非零退出。
10. 测试扩充：test_quantize（溢出断言/误差界/绑定权重）、test_netmeter、test_dataset（规模/平衡/去重/隐私红线）、e2e 管线测试（确定性/埋点齐全/量化管线可跑）。

## 5. 遇到的问题与修复（过程记录）

1. **HF 端点探测误报**：探测 `/{endpoint}/api/models/gpt2` 遇 307 重定向误判不可达 → 改探测站点根路径；hf-mirror 需禁用 xet 后端。
2. **BERT MLM nonzero 索引错误**：1 维张量 `nonzero(as_tuple=True)[1]` 越界 → `[0][0]`（后因 BERT 改为分类口径，MLM 基线整体移除）。
3. **量化器通道维度语义错误**：channel_dim 参数含义与实现不一致，Linear/Conv1D 实际按"输入列"量化而非"输出通道"→ 重写为 out_dim 归约语义 + 单元测试锚定。
4. **GPT-2 绑定权重双重量化**：wte 与 lm_head 共享 Parameter，逐模块量化导致二次量化 → 以 id(param) 去重，量化一次。
5. **一致率 0.89/0.944 不达标排查**：设计隔离矩阵（权重档位 × 激活档位 × no_act 消融）——发现激活 Q13/Q15 单独无影响、主导噪声为权重档位、"Q22 权重 + Q13 激活"组合在 ~1e-5 量级 logit 近并列处混沌翻转 → 激活默认上调 Q16（范围 ±32768 覆盖激活/logits 量级，溢出断言保护）→ 一致率 100%。
6. **FP32 基线自洽性验证**：排除线程非确定性（fp vs fp 20/20 一致）后确认发散来自量化扰动。

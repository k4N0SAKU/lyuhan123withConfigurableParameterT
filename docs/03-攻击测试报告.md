## 1. F7-1 窃听（test_eavesdrop.py，5 项判定全部防御成功）

**攻击者**：Dolev-Yao 被动窃听者，tap 全部三链路（`RecordingEndpoint` 记录
两端发出字节全集），离线四类分析。

| 用例 | 断言 | 关键证据 |
|---|---|---|
| 明文模式扫描 | 输入串（UTF-8/GBK）、token id、Q16 定点秘密值在线缆字节中出现次数 = 0 | wire 总字节 ~KB 级（玩具参数）；`scan_pattern` 命中 0 |
| 结构解析 | GCM 帧载荷段不含 `Payload` 类型标记（加密）；元数据可见性如实申报 | gcm_frames>0 全部通过；`msg_type/长度/时序` 边界见 docs/02 §7 |
| 频率分析 | GCM 密文字节卡方统计 < 400（均匀性） | chi2 ≈ 自由度量级（255±扰动），JSON 载 `chi2` 实测值 |
| 已知明文相关 | 线缆分享与任意候选明文 8B 流 Pearson \|r\|<0.2 | OTP 掩码使分享与候选统计独立 |
| 综合结论 | 敏感输入/中间明文不可恢复 | 对照：合法流程本身 max_abs_err<1e-5 |

**结论：防御成功**。窃听者视角无明文泄露；统计可区分性≈0。

## 2. F7-2 中间人（test_mitm.py，6 项判定全部防御成功）

**攻击者**：自签证书冒充任一节点（3 种接入方向）+ 异 CA 根证书 + 双向中继。

| 用例 | 断言 | 关键证据 |
|---|---|---|
| 冒充 P0→P1 / P1→P0 / P2→P0 | 诚实端会话≠ACTIVE + 审计留 SECURITY_ALERT | `_accept_cert` 拒绝路径告警（P4/P5 补齐：`"why": "握手证书验证失败…"`、`claimed_subject` 记录冒用身份） |
| 异 CA 根证书 | 同上（合法格式、错信任锚） | CERT_INVALID |
| 双向中继 | 两端各自拒绝+告警 | alerts_total>0 |
| 诚实握手对照 | 同 CA 双方 ACTIVE（不误伤） | ACTIVE/ACTIVE |

**结论：防御成功**。三种伪造接入全部认证拒绝且留痕。

## 3. F7-3 结果篡改（test_result_tamper.py，5 项判定全部防御成功）

**攻击者**：恶意 P2（持通道密钥，可发任意合法通道帧）或任意无钥注入者。

| 用例 | 断言 | 关键证据 |
|---|---|---|
| 篡改输出密文 | CTX_RESULT 验签失败 → 客户端拒绝 | sig_verify=False |
| 篡改签名 | 同上 | sig_verify=False |
| 篡改元数据（cipher_meta） | 同上（元数据入签名覆盖段） | sig_verify=False |
| 无钥伪造整帧 | 伪造签名验签失败 | sig_verify=False |
| 诚实结果对照 | 验签通过（不误伤） | sig_verify=True |

**结论：防御成功**。P2 的 SM2 签名（payload 覆盖段）使任何字段篡改可检测、
不可抵赖；客户端仅在验签通过后解密。

## 4. F7-4 重放（test_replay.py，5 项判定全部防御成功）

| 用例 | 断言 | 关键证据 |
|---|---|---|
| 同会话重放 | SEQ_REPLAY（error_code=5） | seq 单调检查先于解密 |
| 多份连续重放 | 每份均拒绝（无窗口放行） | rejected=3 |
| 跨会话重放 | nonce 绑定校验失败（MAC_INVALID）或 seq 拒绝 | nonce=SM3(sid‖sender)[:4]‖seq |
| ratchet 后旧帧重放 | 全部 seq 拒绝；旧纪元密钥窗口外销毁 | rejected=2 |
| 改 seq 重放 | MAC_INVALID（header 受 AAD 覆盖） | error_code=4 |

**结论：防御成功**。重放在解密之前即被拒（密码上不可绕过：seq 在 AAD 内，
改 seq=tag 校验失败）。

## 5. F8 合谋（test_collusion.py，模式 A 4 项 + 模式 B 5 项）

**出口条件「F8 对模式 A、B 分别执行」落实**：两套独立测试类。

### 5.1 模式 A（全密文）——4 项全部防御成功

| 用例 | 断言 | 关键证据 |
|---|---|---|
| 私钥缺失（结构性） | 合谋上下文 public_only，解密抛 OpNotAllowedError | 结构断言 |
| 明文量级扫描 | 合谋视图无激活量级浮点值 | collect_view 取证 = 0 命中 |
| 已知明文区分攻击 | 候选重加密与持有密文逐字节重合率 ≈1/256；密文尺寸在随机性带宽内（无长度信号） | byte_match_rates 全部≈0.0039 |
| 综合结论 | t=2 输入不可恢复（CKKS IND-CPA） | 计算安全 |

### 5.2 模式 B（混合管线）——t=1 防御成功；t=2 边界演示

| 用例 | 判定 | 关键证据 |
|---|---|---|
| 钩子：输入仅在 P0 内存 | 防御成功 | P1/P2 视图（角色全字段 hex 取证）中输入串/token id 8B 模式命中 0；对照：P0 白名单门确为持钥方 |
| P1 单独（t=1） | 防御成功 | y₁ 与真实明文相关 **r=−0.015**；残差落窗率 true/decoy 差 <0.01（已知模型侧区分攻击无检验力） |
| P2 单独（t=1） | 防御成功 | public_only 结构断言 + −r 与明文相关 ≈0 |
| **P1+P2 合谋（t=2）** | **边界演示** | y₁+(−r) 重构 QKV 输出（max_err≈4e-3，玩具 CKKS 噪声经 768 维求逆放大）→ W_q 求逆回嵌入 → **词表最近邻 token 恢复成功**——与 docs/02 §3.3「P1+P2 合谋=全部中间态明文」失效面声明一致 |
| 综合结论 | 边界演示 | t=1 防御成功（自动化统计断言）；t=2 为声明边界；缓解=模式 A / 2-of-3 门限 |

**陷阱应对（合谋测试不只做"无法直接解密"）**：已按陷阱清单执行三类主动
区分攻击——①P1 侧已知模型残差落窗率检验；②模式 A 候选重加密相关检验；
③t=2 侧嵌入表最近邻 token 重构——均给出量化统计量而非"看起来安全"。

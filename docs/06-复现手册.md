## 1. 前置条件

| 项 | 要求 |
|---|---|
| OS | Windows 10/11（Git Bash）或 Linux |
| Python | 3.10.x（requirements 锁定版本按 3.10.4/Windows 验证） |
| 网络 | huggingface.co 不可达时自动切 hf-mirror.com（脚本内置） |

## 2. 三种复现模式（数据与代码分离声明）

| 模式 | 命令 | 说明 |
|---|---|---|
| 全从零 | `bash scripts/reproduce.sh` | 全新 venv + 模型下载（GPT-2/BERT 经镜像）；**情感微调检查点**需 `python -m benchmarks.finetune_bert` 生成（CPU 数分钟）或经模式 B 复用 |
| 数据复用（推荐） | `A122_MODELS_DIR=/abs/data/models bash scripts/reproduce.sh` | 模型是**数据**不是代码——复用已下载/已微调的模型目录，环境洁净性（全新 venv+依赖）不受影响；本报告的证据日志即此模式 |
| 调试 | `A122_SKIP_ENV=1 bash scripts/reproduce.sh` | 跳过 venv/pip（用当前解释器） |

## 6. 常见问题

- **tenseal 装不上**：Windows 轮子基于 numpy 1.x ABI——确认 numpy==1.26.4；
- **模型下载 404/超时**：脚本自动切 hf-mirror.com；企业代理需手动 export
  `HF_ENDPOINT`；
- **pytest 收集到 slow 用例**：默认 addopts 已排除（`-m 'not slow'`）；
  全量口径显式 `-o addopts=`；
- **端口/防火墙**：回环同机模拟（S8），无真实 socket——无需开端口。

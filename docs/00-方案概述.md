## 1. 现实痛点（题面"典型场景业务需求"的展开）

**场景一：政务。** 12345 市民热线、一网通办、窗口评价等系统把群众的
姓名、证件号、住址与诉求文本一起送入大模型做摘要、情绪研判与工单分派。
按《个人信息保护法》与等级保护要求，这类数据不得明文出域；而直接把文本
粘进公有大模型 API，等于把"张伟，身份证 110101********1234，投诉窗口态度"
原文交给了第三方——**监管风险与业务效率直接冲突**：不用大模型，工单
堆压；用了，隐私裸奔。

**场景二：企业。** 客服工单、故障报单、内部日志里常含客户手机号、订单
号、安全事件细节。企业希望用大模型自动分类定级（敏感单需安全团队介入），
但数据出企业边界即违反内控与行业合规（金融/医疗尤甚）。

**三个共性约束**（题面点名）：
1. **可用不可见**：推理必须完成，但原始输入与中间激活不得泄露给任何一方；
2. **资源可落地**：中小型企业没有 128 vCPU GPU 集群——方案要在普通服务器
   可运行、开销可预期；
3. **商用密码合规**：国内政企采购要求国密算法（SM2/SM3/SM4）支撑身份与
   传输安全，"只有国际算法"在招投标中是硬伤。

**现状做法的差距**：明文直传（无保护）；平台侧隐私条款承诺（不可验证、
不可审计）；传统 MPC/FHE 框架直接上（无国密、无业务身份体系、部署重、
时延或资源失控）——详见 04 文献对比与差距分析。

## 2. 本方案如何解决

**一句话**：三方协同的"密文参与推理"系统——用户输入仅在数据属主 P0 本地
加密，密文与秘密分享在 P1/P2 间流转完成 BERT 推理，结果经白名单解密返回；
控制面（认证/密钥/审计）全链国密。

对应题面要求 1~6 的落点（验收证据为自动化测试与实测 JSON）：

| 题面要求 | 方案要素 | 证据 |
|---|---|---|
| 1 多方密文推理、输入不出本地 | 模式 B：CKKS 密文线性层 + MPC 非线性 + 转换协议（P0 单钥掩码，D5 修订） | 03/04；F1/F2 验收表；`p6_full_bench.json` |
| 2 认证/完整性/密钥全生命周期 | SM2 双向认证+CA 离线证书；SM4-GCM 通道（RFC 8998 锚定）；密钥状态机+两遍覆写销毁+SM3 哈希链审计 | P4 协议族测试；`p4_protocol_bench.json` |
| 3 五类攻击抵御 | 窃听/中间人/篡改/重放/合谋各有自动化用例；威胁模型给出敌手表与模拟器论证 | 02/03；`attack_verdicts.json` |
| 4 四项资源指标 | 代码规模/峰值内存/单轮耗时(分段)/网络字节，≥20 轮 P50/P95 + 环境信息 | 04；`p6_full_bench.json`（a122-perf/1） |
| 5 至多 t 合谋 | n=3, t=1：P1 或 P2 单独不可恢复（OTP/无钥，统计检验）；t=2 失效面如实声明并自动化演示 | 02 §3；03 F8（2 项边界演示） |
| 6 业务痛点+五维对比+复现+创新 | 本文 §1；04 五维表（逐项标数据来源）；06 一键复现；05 两个创新点 A/B | 见各文档 |

**安全边界（如实）**：半诚实参与方 + 恶意网络；t=1 精确到门限——P1+P2
合谋即失守（模式 B 输入隐私止于 t=1；缓解路径=模式 A 全密文或 2-of-3 门限，
见 02 §3.3）。模式 A 在本栈不可实例化（SEAL 参数上限，01 §5.3），不做模拟。

**性能位置（如实）**：密文推理较明文开销约 3 个数量级（12 层 P50 371.8s vs
明文 23.6ms，回环 CPU、截断层——04 §2/§7 两口径声明）。与文献 MPC 方案
同处"数量级开销"区间，差异在结构：同态分段刷新减少交互轮次、转换主导通信
（GB 级/请求的诚实预算）、单机可跑（文献均为 Linux 集群口径）。

## 3. 与现状的差距（诚实清单）

1. **时延差距**：现网明文服务百毫秒级，本方案密文路径分钟级（回环 CPU）
   ——瓶颈为 CKKS 明文矩阵乘与转换往返；GPU/定点线性层/转换批量化是
   工程优化路径（05 §3；[I] 项随真实 socket 化评估）；
2. **模式 A 缺口**：全密文本（题面路线提示之一）受本栈 SEAL 参数上限阻断
   ——理论推演保留，需换 OpenFHE 级后端（01 §5.3 决策记录）；
3. **证书体系演示级**：结构化签名对象，商用需替换 GM X.509 证书链
   （01 §4.1；S4 如实声明）；
4. **纯国密数据面缺口**：控制面全链国密，密文计算引擎为国际标准 CKKS
   ——纯国密同态库依赖国产生态，列为扩展方向（04 §7 合规说明）；
5. **底座模型为演示级**：情感二分类微调（acc 99.0%）+ 截断层数演示管线
   ——业务语义映射为示例，非生产模型（04 §6 精度口径分表）。
6. **外部效度锚点**：~~缺失~~ **已补**（P9 对比实验轮）——ChnSentiCorp 官方
   test 切分三口径实测（FP32 92.83% / INT8+Q16 92.83% / 密文与截断参考一致率
   95%）与 SST-2 对照（92.43%，与 EncFormer 明文基线逐位吻合）已入册
   （benchmarks/results/compare_eval_*.json）；跨域迁移（自建域→公开域）81.58%。

## 密码与协议

| 术语 | 释义 |
|---|---|
| CKKS | 等同态加密方案（Cheon-Kim-Kim-Seung），支持定点数近似计算；本栈经 TenSEAL 0.3.14 捆绑的原生 SEAL（sealapi）实现 |
| 模式 A | 全密文推理路线（全部计算在密文域）。本栈 SEAL 参数上限 2^15 下不可实例化，保留理论推演（01 §5.3） |
| 模式 B | 混合密文推理路线（本方案主线）：密文域线性层 + 秘密分享域非线性 + 转换协议分段刷新 |
| 转换协议 | 密文↔秘密分享的双向转换：入口 P2 密文域加 Enc(r)→P0 掩码解密→y₁ 分发；出口 P1 掩码 s→P2 密文域合成 fresh 密文（01 §7.4） |
| D5（P0 单钥掩码解密） | 团队修订决策：P0 持完整 CKKS 私钥，解密仅经白名单两类（掩码转换值、最终输出）；P1/P2 无任何 CKKS 私钥材料 |
| DecryptionWhitelist | D5 的代码执行点：P0 私钥唯一访问门，白名单外请求拒绝并审计 |
| OTP（一次一密） | 转换掩码的均匀性论证：掩码窗宽 ≫ 值域 ⇒ 单份掩码值信息量为零 |
| ConversionPolicy | 按 CKKS 参数集配置的掩码窗策略（值域/入口窗/出口窗；mode-b 与 p4-toy 两套） |
| gap-block 布局 | 每 token 占 2×block_elems 槽的双拷贝布局（支撑块内环绕旋转） |
| 对角线+BSGS | 矩阵乘的密文打包：对角线提取 + baby-step/giant-step 旋转分解（现役实现） |
| row-sum | 矩阵乘朴素对照实现：循环旋转求和（05 §2 A/B 实测慢 5.39×/5.14×） |
| Remez / minimax | 最小极大多项式拟合算法——GELU/exp/inv 等非线性近似系数的生成方法 |
| RCR（reveal-compute-reshare） | MPC 非线性计算的模拟口径：打开→全精度计算→重分享（S8 如实申报，真实定点求值为遗留研究项） |
| Beaver 三元组 | MPC 乘法的预处理材料 (a,b,c=ab)；本方案离线可信生成（假设 A-1） |
| 转换数 10n | 模式 B 每层 6 次入口转换 + 3 次出口重加密 + 层间/最终——结构守恒公式（01 §7.4，实测 40/80/120=10n） |

## 国密与认证

| 术语 | 释义 |
|---|---|
| SM2 | 国标椭圆曲线公钥密码（GB/T 32918）：签名/加密/密钥协商；签名摘要绑定用途上下文字符串（防跨协议重放） |
| SM2DH | GB/T 32918.3 交互式密钥协商：双临时公钥 + w 截断 + 静态私钥混合（01 §8） |
| SM3 | 国标杂凑算法（256 位）；用于 KDF、审计哈希链、transcript 哈希 |
| SM4-GCM | 国标分组密码的 AEAD 模式——本方案自实现 CTR+GHASH（gmssl 无 GCM），RFC 8998 A.1 外部向量锚定 |
| CA 离线根 | 证书签发根密钥离线生成、不进入在线节点（provision 工具） |
| GM X.509 | 商用证书体系——本方案为演示级结构化签名对象，商用需替换（S4） |
| 国密合规边界 | 本方案：控制面（认证/通道/审计/KDF）全链国密；数据面密文引擎为国际标准 CKKS（04 §7 如实声明） |

## 会话与生命周期

| 术语 | 释义 |
|---|---|
| 会话状态机 | IDLE→NEGOTIATED→ACTIVE→ROTATING→DESTROYED（非法转换拒绝并审计） |
| ratchet | 会话密钥按 K_{i+1}=SM3(K_i‖H_i) 周期前向演化（消息数/字节数触发） |
| 共存窗口 | 轮换后旧纪元密钥保留 N 条（容忍非 FIFO 乱序）后立即覆写销毁 |
| 两遍覆写 | 密钥销毁=随机一遍+全零一遍（进程内存级；不抵御 cold-boot） |
| 哈希链审计 | 审计日志 entry_i.hash=SM3(prev‖canonical_i)，可定位篡改/删除/重排 |
| 白名单解密 | UI/文档对 D5 两类合法解密（掩码转换值、最终输出）的简称；非门限解密 |

## 测评与口径

| 术语 | 释义 |
|---|---|
| P50/P95 | 轮耗时中位数/95 分位（≥20 轮；perf 框架 _stats_block） |
| a122-perf/1 | 本项目性能 JSON 的 schema 版本（统一字段与环境信息） |
| 数据字典 | docs/data_dict.json——头条数字唯一权威来源（陷阱 3） |
| 四项资源指标 | 代码规模（LOC）、峰值内存、单轮推理耗时（分段）、网络通信开销 |
| 精度口径分表 | 性能=截断层（4/8/12，L=2/8）；精度=满配 12 层——两口径禁止混用（陷阱 3 变体） |
| S8（模拟口径声明） | 回环同机三进程/进程内模拟；数字精度与真实 MPC 的差异如实申报处 |
| t=1 / t=2 | 至多 1 方合谋安全（本方案承诺面）；P1+P2 合谋=失效面（02 §3.3 如实演示） |
| 截断演示管线 | 演示与矩阵用 n_layer=2/L=8 BERT——业务标签可信度低于满配（04 §2 注记） |
